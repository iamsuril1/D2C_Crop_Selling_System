# D2C Crop Selling Platform 🌱

A **Direct-to-Consumer (D2C) Crop Selling Platform** that connects farmers directly with consumers, eliminating middlemen and ensuring fair pricing.  
The application is built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)** and provides a scalable, secure, and user-friendly solution for agricultural e-commerce.

---

## 📌 Features

### 👨‍🌾 Farmer Module
- Farmer registration and authentication
- Add, update, and delete crop listings
- Manage crop prices, quantity, and availability
- View orders placed by consumers

### 🛒 Consumer Module
- User registration and login
- Browse crops by category and farmer
- Add crops to cart
- Place and track orders

### 🛠 Admin Module
- Manage users (farmers & consumers)
- Monitor crop listings
- Oversee platform activity

### 🔐 General Features
- JWT-based authentication
- Role-based access control
- Secure
